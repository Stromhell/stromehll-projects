# DumDown character kit

Code-only 2D anime character rig for the DumDown channel. No drawing app needed: everything is SVG generated by `dumdown-kit.js`.

- `dumdown-kit.js` — the rig: characters (4 views), poses, hands, expressions, backgrounds, animation loops, character generator. Works in Node and the browser.
- `render.mjs` — renders animation frames (SVG, or PNG with `--png`) ready for ffmpeg.
- `STYLE.md` — the style rules Claude Code must follow.
- `index.html` — the visual character bible (open it in a browser next to `dumdown-kit.js`).

```bash
node render.mjs --char dum --anim talk --bg room --seconds 3 --png --out frames/shot01
ffmpeg -framerate 24 -i frames/shot01/f%04d.png -pix_fmt yuv420p shot01.mp4
```
