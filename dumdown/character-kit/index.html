DumDown Character Bible

The house style for the channel: TV-anime character design with bold ink lines, two-tone cel shading, big expressive eyes and oversized hands and shoes. Every character, hand, background and animation on this page is generated by dumdown-kit.js, so Claude Code can make new ones that stay on-model.

01 · Style DNA

What we took from your references

Your seven references are TV-anime character sheets: superhero teens, school uniforms, original characters. We keep the visual grammar they share and design our own cast, so nothing copies an existing character.

Golden rule: a DumDown character is readable as a black silhouette at thumbnail size. A big hair shape, oversized hands and chunky shoes do most of that work, so never shrink them to look realistic.
02 · The hosts

Turnarounds: front, three-quarter, side, back

The four views every model sheet needs. The head is a 3D sphere in code, so the hair locks, eyes, ears and mouth move to the right place in each view.

Dum

Expression sheet

13 named expressions. Each one sets the eyes, brows, mouth and comedy marks (sweat drop, anger vein, gloom lines, sparkles) in one call.

Hand sheet

Seven hand poses, each built from a palm, two segments per finger, knuckle creases and nails. Gloves and bandages layer on top. Hands are drawn 1.3× life size on purpose.

03 · Joints and rig

How a 2D character moves

A 2D rig is a tree of bones. Each bone rotates around a pivot at its parent's end, and children follow their parents. This is forward kinematics: rotate the shoulder and the elbow, wrist and hand come along.

The bone tree

pelvis (root: moves the whole body, bob)
├─ spine → chest (lean)
│   ├─ neck → head (tilt)
│   ├─ shoulder.L → elbow.L → wrist.L → hand.L
│   └─ shoulder.R → elbow.R → wrist.R → hand.R
├─ hip.L → knee.L → ankle.L → foot.L
└─ hip.R → knee.R → ankle.R → foot.R

Joint rules

0° points straight down. A positive angle swings the bone's far end to the viewer's right. Child angles are relative to the parent.

Elbows bend one way, knees the other. In side view a positive elbow angle bends the forearm forward; the knee value bends the shin backward. Keep knees between 0° and 130°, and elbows between 0° and 150° in their natural direction.

Joints overlap, they don't hinge. Each limb is a tapered capsule with a round end, so a bent elbow or knee stays solid instead of breaking into a gap. The upper bone is drawn over the lower one so the sleeve edge reads.

Near limbs in front, far limbs behind and slightly darker in three-quarter and side views. That alone sells depth.

04 · Small animations

Five loops that cover most of an explainer

Each loop is a function of time that returns a pose and an expression. They are timed "on twos": every drawing holds for two frames at 24fps, which gives the snappy TV-anime feel. Turn it off to see the smooth version.

05 · Backgrounds

Painted-look backgrounds, also in code

Backgrounds use no outlines on far objects and ink lines only on near props, flat gradient skies, two-tone clouds and lots of small detail: windows, tapes on shelves, power lines. Each one takes a seed, so you get a new variation of the same place every time.

Depth recipe: far layer is low contrast and tinted toward the sky; mid layer gets windows and rim light; near layer gets full ink lines and cel shadows. Characters always sit on the near layer with a soft contact shadow under their feet.
06 · Make a new character

Character generator

A seed picks hair style, palette, outfit, body proportions and accessories from the approved style rules. The same seed always gives the same character, so you can write the seed into a script and get them back later.


  


  
  

    

      07 · Using it with Claude Code
      
Workflow

      
The kit is one JavaScript file with no dependencies. It runs in Node and in the browser, and it writes plain SVG. Claude Code can make sheets, stills, and video frames you can turn into MP4.

    

    
    
      
  1. Put dumdown-kit.js and render.mjs in your project folder.
    2. 
      
  2. Start from a cast member, or call generateCharacter('any seed') and edit the spec it returns.
    3. 
      
  3. Pick a view, pose, expression and background per shot.
    4. 
      
  4. Run node render.mjs to write SVG frames, then convert them to PNG and stitch with ffmpeg (commands below).
    5. 
    

    

      
const D = require('./dumdown-kit.js');

// a still: Dum, 3/4 view, pointing, smug, on the street
const W = 1280, H = 720;
const art = D.drawBackground('street', W, H, 21)
  + D.drawCharacter(D.CAST.dum, {
      view: 'threequarter', x: 520, y: 690, scale: 1.4,
      pose: D.POSES.point, expr: 'smug' });
require('fs').writeFileSync('shot01.svg', D.svg(W, H, art));

// a new character, then tweak the spec like normal JSON
const villain = D.generateCharacter('popcorn-villain');
villain.hair.style = 'spiky';
villain.top.emblem = 'zz';

      
# 2 seconds of Dum talking, 24fps, on twos
node render.mjs --char dum --anim talk \
  --bg room --seconds 2 --out frames/

# SVG → PNG (any one of these)
npx @resvg/resvg-js-cli frames/f0001.svg f0001.png
# or: rsvg-convert, inkscape, or Playwright screenshots

# PNG frames → MP4
ffmpeg -framerate 24 -i frames/f%04d.png \
  -pix_fmt yuv420p dum_talk.mp4
