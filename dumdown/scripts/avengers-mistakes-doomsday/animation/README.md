# Avengers Mistakes (DumDown 12) build
Engine = Secret Invasion engine (branch claude/project-thread-ckcepc) on top of The Marvels animation (branch claude/project-thread-lu1yci) + acting.js/sbprops.js/vo_cb from Spider-Man BND (branch claude/project-thread-p09u9z).
This folder holds only the new/changed files: cast.cjs (adds the Avengers parody cast), am_kit.js (capes, hood, face plate, third eye), amprops.js (thank-you list, scroll, DOOM-O-METER...), am_help.js (inline gag helpers), acts/, gags/ (inline gag data + audio), mk_timing.py (merges narrator VO + gag audio into one act timeline), am_plates.json (SDXL-turbo plate prompts, tools/sdgen from BND).
Gags are built INSIDE the acts (Pushpam 22 Nov 2026).
