# Video handover (fill in when a video and its reels are done and scheduled)

Save as `<video folder>/05 Production/HANDOVER.md` in the repo and on Drive (same folder), then resolve the thread. The next video starts in a NEW thread that reads only this file, which is the cloud version of `/clear`.

## 1. Video
- Title / line (2D, 2D dynamic, 3D low, 3D):
- Final full video: repo path + Drive link
- Reels / IG parts / thumbnail: paths + Drive links
- Zernio bookings (UTC + UK + ET): full video, reels, IG parts

## 2. What was done
- Script, storyboard, voice, acts (count), checkup rounds, combine: one line each with final file names

## 3. Reusable for the next video (the only part the next thread should read)
- Sets / cast / props files worth reusing (paths)
- Build commands that worked (exact)
- QA issues found and how they were fixed (one line each)
- Gotchas (render times, disk, tools that failed)

## 4. Open items
- Anything not finished, who owns it, where it's tracked (Control Room card id)

## 5. Cleanup done
- Scratch / render caches deleted from the container: yes/no
- Control Room card removed: yes/no
