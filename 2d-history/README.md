# 2D history videos

Everything the 2D history thread makes, one folder per video.

```
2d-history/
  handover/                 rules for this channel (Project Handover v1)
  shared/                   tools used by every video
    gen.py                  build/data.py -> script .md, storyboard page, voice text
    sketch.js, mksketch.js  pencil storyboard sketches
    mkspecs.py              sketch specs from build/data.py
    kit.js, rig.js          scene kit and character rig for the animation
    p2/                     code painter for background plates
    render.js               renders an act page to frames
    fonts/
  <video>/
    source-transcript.md    the transcript we started from
    <video>-production-script.md
    build/data.py           script, shots, sketch specs, animation notes, launch package
    storyboard/             storyboard page + sketches/
    production/             voice text, plates, act renders (as they are made)
    launch/                 thumbnail, title, description, reels (after combine)
```

Large renders over GitHub's 100 MB limit are kept as a smaller copy here, with the full file on Google Drive (AI / long form history video / <video>).
