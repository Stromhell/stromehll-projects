Lessons for the next video:
- remix2.py reuses an existing actN_dry.mp4. Before re-rendering an act, move the old dry file away, otherwise the old visuals ship.
- GM.ntag: `col` is the TEXT colour, `bg` is the pill colour. Pale col on the default cream pill = blank-looking tags.
- Counters for "1,000s" style text: don't count up from 0 (reads "0s").
- qa_lean on a 9-min full times out in the Qwen stage after 45 min; qa_auto + vo_check finish first and are usable. Shimmer flags on smoke plumes and waving crowds are false positives.
