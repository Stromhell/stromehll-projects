# Rubber Hose Style Bible (v1, project name to come)

1930s rubber-hose cartoon style, built from Pushpam's 14 Pinterest pins (12 Nov 2026), done fully in code.

- `rh.js` – the whole kit: character rig (RH.character / RH.draw / RH.stand / RH.anim.*), gloves, shoes, faces, hair, hats, clothes, painted backgrounds (RH.bg.street/forest/room), film finish (RH.film), generator (RH.random).
- `cast.js` – 5 placeholder test characters.
- `guide.src.html` – page source; `guide.html` – built page (rh.js + cast.js inlined).
- Live page: https://claude.ai/artifact/WcdnCieuxDM4GDnD47L2LJ

Rebuild page: replace `/*RH_JS*/` and `/*CAST_JS*/` in guide.src.html with the file contents.
