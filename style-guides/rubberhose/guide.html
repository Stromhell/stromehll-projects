Rubber Hose Style Bible

A 1930s rubber-hose cartoon look, rebuilt as code. Every character, glove, shoe, face and background on this page is drawn live by one JavaScript file (rh.js), so Claude Code can make new characters and scenes that keep this exact feel.

01 · What we took from your pins

Style DNA

Pins 1 to 5 are 1930s rubber-hose characters (round heads, pie-cut eyes, white four-digit gloves, big shoes, bendy limbs, thick warm ink). Pins 6 to 14 are movement references: walk and run cycles, game sprites, sneaks and a talking kid. This page turns both into rules.

Shapes

  • Head is the biggest shape, about one third of the height.
  • Pear, barrel or slim torso. No necks.
  • Limbs are tubes of one fixed width with no elbows or knees drawn.

Line

  • One warm near-black ink, about 3 px at 1x.
  • Outline the whole silhouette, never the inside overlaps.
  • Clothing seams and folds get thinner lines at half opacity.

Colour

  • Muted print colours, never neon.
  • Light from the top left. Shadow is the same colour, darker and slightly purple.
  • Halftone dots inside the shadow side, like old printed comics.

Faces

  • Tall eyes that touch, with pie-cut black pupils.
  • Button nose, blush ovals, a smile with tick marks at the corners.
  • Expressions come from lids and brows first, the mouth second.

Hands and feet

  • White gloves with three fingers plus a thumb, a flared cuff and three stitch lines.
  • Shoes are big round bulbs with a pale sole, a shine and laces.
  • Gloves are about the size of the face.

Texture and motion

  • Paper grain, soft vignette, gentle film flicker.
  • Everything bounces: idle on the beat, squash on landing, stretch on the way up.
  • Animate on twos (12 drawings a second) for the vintage feel.

02 · Test cast

Five characters, one rig

03 · Model sheet

Turnarounds

Front, three-quarter, side and back. Pick a character. The rig moves the face across the head, squeezes the body width and swaps ear, hair and hat drawings per view, so any new character gets all four views for free.

04 · Acting

Expressions and mouth shapes

Ten expressions and ten mouth shapes. For lip sync, map sounds to mouths: M B P → M, A I → open, E → E, O U W → O, rest → smile.

05 · Gloves

Seven hand poses

Hands are drawn outline first, fill second, so the fingers merge into one clean glove shape. Each pose is a short list of ovals and finger tubes, so adding a new pose is a few lines.

06 · How 2D bodies move

Joints and movement

The rig has only the joints you can see on the left. Arms and legs are rubber hoses: each one has a fixed length, a start joint and an end point. When the end comes closer, the hose bows out in a smooth curve, and that curve is the elbow or knee. When the end goes further, the hose stretches. That is the whole rubber-hose trick, and it is why these limbs never break.

What each joint does

  • Pelvis: moves up and down for bounce, leans the upper body.
  • Neck: tilts the head, which lags behind the body by a few frames.
  • Shoulder and hip: the start of each hose. Fixed to the body.
  • Elbow and knee: not real joints. The bend point is worked out from limb length, so it always lands on a smooth arc. Knees bow forward, elbows bow back.
  • Wrist: where the glove sits. The glove turns to follow the forearm unless a pose fixes its angle (dangling sneak fingers, waving).
  • Ankle: where the shoe sits. The shoe rolls heel to toe through a step.

Twelve rules of good motion we follow

  1. Squash on landing, stretch on the way up. Keep the volume the same.
  2. Anticipation: crouch before a jump, wind up before a take.
  3. Follow-through: hats, braids and tails stop after the body.
  4. Arcs: hands, feet and heads travel on curves, never straight lines.
  5. Slow in and slow out at the ends of a move; the sneak holds each step.
  6. Opposite arm swings with each leg.
  7. The body is lowest just after the heel lands and highest while passing.
  8. Heel hits first, toe pushes off last.
  9. Things never pop in: they walk, slide or bounce in.
  10. Feet stay planted on the ground line; the contact shadow shrinks when off it.
  11. Keep a few frames of hold so the audience can read a pose.
  12. Blink every 3 seconds or so, and on big head turns.

Walk cycle, frame by frame

One full cycle is two steps. The red dotted line on frames 1 and 5 is the arc the front foot travels through a full cycle.

07 · Small animations

Seven motion tests

Each one is a single function of time. Pass in the seconds, get back a pose, draw it. Turn off "on twos" for smooth 60 fps.

08 · Painted sets

Backgrounds

Backgrounds are drawn in a fixed 1600 × 900 world, painted in layers from back to front, then finished with a warm wash, paper grain and a vignette. Change the seed and a whole new street, forest or room comes out with the same style.

seed 5

Layer recipe

  • 1. Sky gradient + soft wash dabs
  • 2. Sun glow and inked cream clouds
  • 3. Far silhouettes, paler and bluer
  • 4. Main set pieces with ink outlines and texture
  • 5. Ground: tiles, cobbles, planks or grass
  • 6. Props and foreground details
  • 7. Light shafts, wash, grain, vignette

Detail checklist

  • Every surface gets a texture: bricks, grain, bark, cobbles.
  • Windows get frames, curtains, sills and flower boxes.
  • Ink lines wobble slightly so they look hand drawn.
  • At least three props per set at real size next to the cast.

Keep the cast readable

  • Sets are lower contrast than characters.
  • The ground line sits at 70 to 80 percent of the height.
  • Keep the busiest detail away from where faces go.

11 · For Claude Code
Using the kit
Everything lives in style-guides/rubberhose/: rh.js (the whole kit), cast.js (the test cast), and this page. Load rh.js in any HTML page or render script.

  

    
1. Make a character
const pip = RH.character({
  name: 'Pip Tumble', skin: '#f1c9a0', freckles: true,
  head: { shape: 'round' },          // round | bean | long
  hair: { style: 'tuft' },           // tuft curls slick bun braids bald spiky
  hat:  { type: 'cap', color: '#5b6e4e' }, // none top bowler cap boater
  body: { shape: 'pear' },           // pear barrel slim tall
  top:  { type: 'shorts', color: '#c2372d', accent: '#2b2523' },
        // tee shorts overalls tux dress
  nose: 'button', eyes: 'pie', tie: 'none'
});

    
2. Pose it and draw it
// still pose in any view: front | q | side | back
RH.draw(ctx, pip, RH.stand('q'), x, groundY, scale);

// animation: any RH.anim.* is a function of time
const pose = RH.anim.walk(t, 'side');
pose.dir = -1;                       // face left
RH.draw(ctx, pip, pose, x, groundY, scale);

// faces and hands
pose.face = { expr: 'angry', mouth: 'grit', look: [1, 0] };
pose.arms[1].hand = 'point';

    
3. Backgrounds and finish
const street = RH.bg.render('street', 1920, 1080, seed);
ctx.drawImage(street, 0, 0);         // also 'forest', 'room'
// ...draw characters...
RH.film(ctx, 1920, 1080, t);          // grain + flicker per frame

    
4. Rules for every new character
    
      
  • Start from RH.character(); never draw a body by hand.
    • 
      
  • New hair, hats or clothes go into rh.js as a new option, so every view works.
    • 
      
  • Check all four views and three expressions on a sheet before animating.
    • 
      
  • Keep heads about one third of the height and gloves face-sized.
    • 
      
  • Use only the palette colours, or mix two of them.
    • 
      
  • Every scene: a set from RH.bg, contact shadows, film finish.
